# Glossário — Lançamento do Letra

## Produto

| Termo | Definição |
|-------|-----------|
| **Letra** | Mission Control para engenharia assistida por IA |
| **Workspace** | Unidade de valor no Letra; representa uma solução em progresso |
| **Harness** | Conjunto de regras, templates e configurações que definem o comportamento do Letra |
| **Flow** | Fluxo de trabalho orquestrado com etapas, gates e entregas |
| **Gate** | Ponto de aprovação humana antes de avançar para a próxima etapa |
| **Stage** | Etapa do fluxo (backlog, design, code, review, done) |
| **Spec** | Especificação de um item de trabalho com ACs (Acceptance Criteria) |
| **AC** | Acceptance Criteria — critério binário de aceitação (passa/falha) |

## Marca

| Termo | Definição |
|-------|-----------|
| **Slogan principal** | "Da intenção à entrega" |
| **Slogans alternativos** | "Orchestrate agents. Ship software.", "AI agents, human control" |
| **Arquétipo primário** | Governante — organiza, orienta, dá visibilidade |
| **Arquétipo secundário** | Sábio — inteligência estruturada, não mística |
| **Visual flow** | `●──●──●──◆` — nós=agentes, linhas=handoffs, losango=entrega |

## Técnico

| Termo | Definição |
|-------|-----------|
| **UI** | Interface do usuário (Web UI do Letra) |
| **CLI** | Command Line Interface (terminal do Letra) |
| **SPA** | Single Page Application |
| **Brand tokens** | Variáveis CSS que definem cores, fontes e espaçamentos da marca |
| **Design system** | Sistema visual completo (componentes, padrões, guidelines) |

## Lançamento

| Termo | Definição |
|-------|-----------|
| **Waitlist** | Lista de espera para early access ao produto |
| **Soft launch** | Lançamento limitado para validar antes do lançamento público |
| **Public launch** | Lançamento completo para o público geral |
| **Go-to-market** | Estratégia de entrada no mercado |
| **MQL** | Marketing Qualified Lead — lead qualificado pelo marketing |
| **PLG** | Product-Led Growth — crescimento liderado pelo produto |

## Métricas

| Termo | Definição |
|-------|-----------|
| **LCP** | Largest Contentful Paint — métrica de performance (target: < 2.5s) |
| **CLS** | Cumulative Layout Shift — métrica de estabilidade visual (target: < 0.1) |
| **Lighthouse** | Ferramenta de auditoria de performance, acessibilidade e SEO |
| **Conversion rate** | Taxa de conversão (visitantes → waitlist signups) |
| **Bounce rate** | Taxa de rejeição (visitantes que saem sem interagir) |
