# Spec: launch-campaign

> Updated: 2026-07-03

## Outcome

O público-alvo consegue:
1. Descobrir o Letra através de múltiplos canais
2. Entender o problema que o Letra resolve
3. Ver demos e exemplos de uso
4. Fazer join na waitlist
5. Acessar documentação e recursos

## Constraints

- Seguir voice.md rigorosamente (técnica, sem hype)
- Usar apenas assets aprovados no brand-book
- Timing: soft launch semana 3-4, public launch semana 5+
- Budget: priorizar canais gratuitos e orgânicos

## Exclusions

- **NÃO** inclui paid advertising (v1 é orgânico)
- **NÃO** inclui outreach individual (v1 é broadcast)
- **NÃO** inclui eventos presenciais
- **NÃO** inclui parcerias formais

## Acceptance Criteria

- [x] **AC-1**: Blog post de lançamento com 1500+ palavras, storytelling e CTA
- [x] **AC-2**: 10+ posts para social media (Twitter, LinkedIn) com copy aprovada
- [x] **AC-3**: Thread no Twitter com 5-7 tweets explicando o Letra
- [x] **AC-4**: Post no LinkedIn com 300-500 palavras para audiência profissional
- [x] **AC-5**: Email sequence de lançamento (3 emails: announcement, demo, social proof)
- [x] **AC-6**: Assets visuais para social media (5+ imagens)
- [x] **AC-7**: Video demo de 60 segundos (script + storyboard)
- [x] **AC-8**: Lista de 20+ communities para compartilhamento (dev communities, Reddit, HN, etc.)
- [x] **AC-9**: Template de launch checklist para execution
- [x] **AC-10**: Calendar de conteúdo com 2 semanas de posts programados

## Context

A campanha de lançamento é essencial para gerar awareness e tráfego inicial. Ela serve para:
- Posicionar o Letra no mercado de AI-assisted development
- Gerar buzz e expectativa antes do lançamento
- Atrair early adopters qualificados
- Estabelecer autoridade no espaço

**Trade-offs considerados:**
- Blog post longo vs. curto → longo (1500+ palavras) para SEO e autoridade
- Muitos canais vs. poucos → focar nos 3 principais (Twitter, LinkedIn, communities)
- Video profissional vs. screencast → screencast para MVP, profissional depois
- Email sequence vs. email único → sequence para nurturer leads
