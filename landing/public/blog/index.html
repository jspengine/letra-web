The Problem: Agents Without a Map

AI code assistants are incredible. They generate code, debug issues, write tests. But there's a catch: each agent works in isolation. There's no shared context, no coordinated handoff, no human supervision at critical points. The result is speed without direction.

Teams using AI tools face three challenges:

1. Context fragmentation. Each agent starts from scratch. What one agent learns, the next doesn't know.

2. No supervision. Code goes from generation to production without human review at the right moments.

3. Black box delivery. When something breaks, there's no trace of which agent did what, when, or why.

The Solution: Orchestration, Not Automation

Letra is not another AI code generator. It's a coordination layer that sits between you and your AI agents, managing context, enforcing gates, and recording every decision.

The core insight: AI agents are tools. Tools need operators. Operators need dashboards, controls, and feedback loops. That's what Letra provides.

"Letra exists to transform human intent into working software with operational precision."

How It Works

Letra organizes work through workspaces. Each workspace holds specs, flows, agents, and evidence. Work progresses through stages — backlog → design → code → review → done — with gates at each transition requiring human approval.

Behind the scenes, agents (LLMs with configured personas) execute the work. Their output is always presented for human approval before any side effect.

What's Coming in v1

Workspace model: Self-contained units with full context, rules, and state. Flow engine: Move work through lifecycle stages with gates. 3 agent personas: reviewer, security, analyst — each with explicit constraints. Full traceability: Every action produces an artifact. No black boxes. CLI + Web UI: Terminal-first with a companion SPA.
